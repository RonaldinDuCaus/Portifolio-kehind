# Portfólio de Guilherme Kehinde Martins de Campos

Portfólio acadêmico de Internet das Coisas (IoT), Senac Nações Unidas.

Abra `index.html` ou visite o site pelo GitHub Pages quando estiver habilitado.

As sete páginas incluem Início, Áreas do Saber, Formação Técnica, Currículo, Memórias, Jornada e Contato.

As pastas de mídias contêm instruções para adicionar evidências reais. Antes de publicar dados de contato pessoais de um menor, confirme a autorização.
